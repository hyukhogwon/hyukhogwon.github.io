# 권혁호 포트폴리오

복잡한 업무 규칙을 명시적인 모델과 검증 가능한 구조로 바꾸는 프론트엔드 엔지니어 권혁호의 포트폴리오입니다.

## 실행

```sh
npm install
npm run dev
```

## 검증

```sh
npm test
npm run build
npm run test:e2e
```

- Vitest: 공개 콘텐츠 내부 식별 정보 검사
- Astro check/build: 타입 검사와 8개 정적 페이지 생성
- Playwright: 데스크톱·모바일 홈 및 프로젝트 상세 검증

`main` 브랜치에 반영하면 GitHub Actions가 GitHub Pages에 배포합니다.
